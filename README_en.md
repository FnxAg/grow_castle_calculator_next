<h2 align="center">Grow Castle Calculator Next (GCC Next)</h2>

<p align="center">A game tool for Grow Castle developed with Flutter.</p>

## Installation

|Platform|Download|
|---|---|
|Android / Windows|[GitHub](https://github.com/Fnxag/grow_castle_calculator_next/releases)|

## Features

- Multi-user management
- Build GP calculation
- Income calculation
- Game track recording
- Leaderboard
  - Player leaderboard, guild leaderboard, hell mode leaderboard
- WPH query (third-party API)
- Dragon farming simulator
- Item comparison
- Localization
  - Simplified Chinese, Traditional Chinese, English
