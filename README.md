<h2 align="center">Grow Castle Calculator Next (GCC Next)</h2>

<p align="center">使用 Flutter 开发的成长城堡 (Grow Castle) 游戏工具。</p>

## 安装

|平台|下载|
|---|---|
|Android / Windows|[GitHub](https://github.com/Fnxag/grow_castle_calculator_next/releases)|

## 特点

- 多用户管理
- 阵容经济计算
- 收入计算
- 记录游戏轨迹
- 榜单查询
  - 个人赛季榜、公会赛季榜、无尽榜
- 波速查询（第三方 API）
- 刷龙模拟器
- 装备比较
- 本地化
  - 简体中文、繁體中文、English
